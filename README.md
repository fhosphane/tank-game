# TankGame (JavaFX)

2D tank game built with Java & JavaFX.

## Controls
- Arrow keys: Move
- X: Shoot
- P: Pause/Resume
- R: Restart (when paused or game over)
- ESC: Exit (when paused or game over)

## Run (Developer)
./gradlew run

Linux: zip aç → TankGame/bin/TankGame

Windows: zip aç → TankGame/bin/TankGame.exe
